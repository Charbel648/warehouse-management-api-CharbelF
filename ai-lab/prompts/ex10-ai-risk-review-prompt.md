# Exercise 10 Prompt History — AI Risk Review

## Prompt sent to AI

You are reviewing the risk of using generative AI in backend engineering for an ASP.NET Core Warehouse Management API.

The project uses:
- Clean Architecture
- ASP.NET Core Controllers
- MediatR/CQRS handlers
- Domain models and business rules
- EF Core repositories
- Firebase authorization policies
- MinIO object storage
- RabbitMQ notification events
- Unit tests and WebApplicationFactory integration tests

Complete an AI backend risk review table with the following required rows:

1. wrong validation
2. insecure file upload
3. incorrect EF logic
4. missing auth mappings

For each row, provide:
- risk
- impact
- mitigation
- human verification step

Also summarize what human review is required before accepting AI-generated backend code.
